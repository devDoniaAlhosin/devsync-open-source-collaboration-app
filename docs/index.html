HANDOFFS · NO SHARED LAYER

How we stay out of each other’s way

Nobody owns the same feature. The only overlaps are two people on one screen, and each person owns a different layer. Freeze the contract first, then code in this order.

Match feed

Emad · ranking + cardYousef · like/skip

One screen, two widgets. Emad owns score, reason, list, and card layout. Yousef owns the like/skip buttons and the Firestore feedback documents. Yousef does not change ranking. Emad does not change like/skip storage.

  • Monday 23 Oct: freeze item JSON — projectId, name, score, reason, skills[]
  • Wednesday 25 Oct: Emad merges the feed card
  • Thursday–Friday: Yousef wires like/skip onto that card
  • Emad starts prompt evaluation only after feedback documents exist

Settings

Donia · account + securitySaga · GitHub + about

Donia is the screen owner. Saga does not edit the whole page. She opens a pull request only for the GitHub connection and About / build block.

  • Donia: session, email or Google, sign-out, permissions
  • Saga: GitHub link, Free/Pro flavor, about and build info
  • Donia reviews Saga’s Settings pull request

Animations on other screens

Bishay · motion onlyScreen owner · review

Bishay never branches from an unfinished screen. He changes animation only: no Firestore, no business logic, no copy.

  • Owner merges the screen to develop with no motion polish
  • Bishay opens a motion branch from that merge
  • The screen owner reviews within 24 hours

Load, not a new owner

Donia · 12 pts + PMBishay · 7 pts, helps first

Do not move Auth or Security to someone else. That creates a new conflict. If Donia is behind, Bishay reviews Auth UI and prepares Projects on mock data. Cut if-time items before changing ownership.

Week 2 order · 23–29 Oct

Do blockers in this sequence so people are not waiting on each other.

  1. By 22 Oct — Donia: foundation collections and field names in the README
  2. By 22 Oct — Yousef: app shell with stub routes
  3. By 22 Oct — Saga: GitHub sample JSON
  4. Mon 23 Oct — Bishay: seed projects in Firestore or mock data
  5. Mon 23 Oct — Donia: user document with uid and FCM token field
  6. Wed 25 Oct — Emad: feed card merged
  7. Fri 29 Oct — Yousef: like/skip stored; request shape agreed
  8. Fri 29 Oct — Donia, Saga, Bishay: auth, profile, and projects landed

Monday standup is a capacity check: is the JSON frozen, and who is blocked? Backup chain stays Donia → Yousef → Saga → Bishay → Emad → Donia.
